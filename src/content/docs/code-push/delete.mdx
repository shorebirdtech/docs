:::danger[Deletion is permanent]

Deleting an app, a release, or a patch **permanently** removes it and all of its
data. It is **not restorable**. There is no trash, no archive, and no undo, and
Shorebird support cannot bring it back for you.

:::

The Shorebird console shows a confirmation dialog before any of these deletions.
That dialog is the last chance to change your mind: once you confirm, the data
is gone.

## What each deletion removes

| You delete | What is permanently removed                                                       |
| ---------- | --------------------------------------------------------------------------------- |
| A patch    | Patches cannot be deleted on their own. They are removed with their release.      |
| A release  | The release, its artifacts, and every patch published to it (per platform).       |
| An app     | The app and every release, patch, and artifact belonging to it.                   |
| An account | Your personal organization and all of its apps, releases, patches, and artifacts. |

## Delete a patch

There is no way to delete an individual patch. Patches are deleted only when the
release they belong to (or the app that owns that release) is deleted, and that
deletion is permanent.

If you want to stop serving a patch, **roll it back instead of deleting the
release**. A rollback remotely uninstalls the patch from end users' devices and
falls back to the previous patch or the base release. Unlike a delete, a
rollback can be undone.

## Delete a release

Deleting a release permanently deletes the release, its artifacts, and every
patch published to it for the platforms you select. Devices will no longer
receive patches for that release version.

See [Delete releases](/code-push/release#delete-releases) for the steps and for
the platform selection dialog.

## Delete an app

1. Navigate to the app in the
   [Shorebird console](https://console.shorebird.dev/).
2. Go to the **Settings** tab.
3. In the **Danger Zone**, select **Delete**.
4. Confirm in the dialog that appears.

Deleting an app permanently deletes every release, patch, and artifact
associated with it. Copies of the app that are already installed on end users'
devices keep working normally, but they will never receive another patch.

If you only want to hand an app to someone else, use **Transfer Ownership** in
the same Danger Zone rather than deleting it.

## Delete an account

Account deletion is also permanent. It removes your personal organization and
everything in it. If you own any team organizations, you must transfer or delete
those first.

## Before you delete

Because none of this can be undone, consider whether one of these does what you
actually want:

- **A bad patch is live.** [Roll it back](/code-push/rollback). It is
  reversible.
- **You want to test a patch first.** Publish to a
  [staging track](/code-push/guides/staging-patches) instead.
- **You are handing off an app.** Transfer ownership of the app or the
  [organization](/account/orgs) instead of deleting it.

If you are unsure, [reach out](mailto:contact@shorebird.dev) _before_ you
delete. Support cannot help afterwards.
